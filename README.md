# Redesigned Existence — Pack 1

Seven Claude Code skills that make your AI act less like a search engine and more like a sharp colleague.

No API keys. No Python. No setup pain. Drop seven folders in the right place and you're done.

## What you get

| Skill | What it does | When to use |
|---|---|---|
| `voice-mirror` | Learns your writing voice from 5 samples, applies it to anything you make | Every time you draft something |
| `thought-partner-skeptic` | Responds as a peer who pushes back with evidence instead of agreeing | When you need someone to stress-test your thinking |
| `meeting-blindspot` | Reads a transcript and shows you where you should have pushed back | After any meeting that mattered |
| `inbox-intent-triage` | Sorts emails by whether they advance your goals, not by time | Daily or when inbox is overwhelming |
| `offer-stress-test` | Red-teams any offer, pitch, or sales copy — 7 reasons a buyer says no | Before you ship any pitch |
| `weekly-compound` | Friday ritual that shows what compounded, what leaked, and what bet to make next | Once a week, same day |
| `decision-journal` | Logs decisions with schema so your AI can reason across them later | Every time you make a real call |

Each skill is a single markdown file. No code runs. Claude reads the instructions and follows them.

## Install in 60 seconds

See **[INSTALL.md](INSTALL.md)** for the exact step-by-step. Made for people who have never used a terminal.

Short version:

1. Download this repo (green **Code** button at top → **Download ZIP**).
2. Unzip it.
3. Copy the `.claude/skills/` folder into your home folder (Mac: `~/.claude/skills/`. Windows: `C:\Users\YourName\.claude\skills\`).
4. Open Claude Code.
5. Type `/voice-mirror` or any other skill name.

## Use in Claude.ai (web, no install)

If you don't use Claude Code, every skill still works in Claude.ai:

1. Open any `SKILL.md` file in this repo.
2. Copy everything **below** the block that starts and ends with `---`.
3. Paste it as your first message in a new Claude chat.
4. Type your request after.

## Which skill first?

If you're new to all of this, run them in this order:

1. **`voice-mirror`** — Build your voice profile once. Every other skill gets sharper when you have one.
2. **`decision-journal`** — Start logging decisions. Small friction now, huge payoff in six weeks.
3. **`thought-partner-skeptic`** — Use it on your next idea you're excited about. See what falls.
4. **`weekly-compound`** — Set a Friday calendar block. Do it once, you'll do it forever.
5. **`offer-stress-test`** — Next time you write anything that asks for money or a yes.
6. **`meeting-blindspot`** — Your next meeting that has stakes.
7. **`inbox-intent-triage`** — When your inbox is loud and you're small.

## What makes these different

Most public AI skills wrap a basic task: write an email, summarize a meeting, make a list. These don't do that. Every skill here is built around a small philosophy:

- The AI should work against your defaults, not with them.
- Context about you beats clever prompting.
- Good skills force structure, not just output.
- Pattern recognition beats single answers.

You'll feel this most after using any skill for the third time. The outputs sharpen. That's the design.
